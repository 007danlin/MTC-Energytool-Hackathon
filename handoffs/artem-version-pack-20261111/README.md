# Пять версий для Артёма

Рабочая база — A2 (55.969). E4, G и V3 — сравнительные версии с платформенными результатами. A3/R7 — отрицательный диагностический пример без платформенного балла. Это версии программы, а не пять разных весовых моделей.

- [A2](a2.md)
- [E4](e4.md)
- [G](g.md)
- [V3](v3.md)
- [A3 / R7 — отклонённый эксперимент](a3-r7.md)

Порядок работы: сохранить A2, менять поиск отдельно от генерации, проверить нужные факты и ограничения, затем качество ответов. Не смешивать результаты разных выборок в один рейтинг. Ссылки ведут в текущий репозиторий: при передаче документов отдельно нужно передать и указанные архивы/отчёты.
