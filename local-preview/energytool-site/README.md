# Сайт с работающим консультантом

Полная связка сайта, Go-бэкенда и Python запускается из корня проекта:

```sh
cp .env.web.example .env.web  # только при первом запуске
# Ollama должна быть запущена; модель из примера уже установлена на рабочем Mac.
docker compose -f compose.web.yaml up --build -d
```

Открыть http://127.0.0.1:8768 и нажать «Онлайн-консультация». История и черновики заявок сохраняются в Docker volume. [Настройки, проверки и ограничения](../../docs/web-stack.md).

`serve.py` раздаёт сайт и перенаправляет `/api/v1/*` в Go API по `BACKEND_URL` (по умолчанию `http://127.0.0.1:8080`). При отдельном запуске без Go чат недоступен. Полноэкранный интерфейс по макету Георгия включает новый диалог, историю, закрытие, источники и сохранение подтверждённой заявки. Текст модели выводится как текст, без исполнения HTML.

# Energytool — локальная копия для демонстрации

Открыть запущенную копию: http://127.0.0.1:8767

Повторный запуск из этого каталога:

```sh
python3 serve.py
```

После запуска открыть адрес выше. Остановить сервер — Ctrl+C. Нужен Python 3; дополнительных библиотек не требуется. На macOS можно дважды нажать `start.command`.

Не открывайте `www/index.html` двойным щелчком: оригинальное React-приложение использует абсолютные пути и маршруты, для которых нужен HTTP-сервер.

Восстановлены оригинальный React-интерфейс, стили, шрифты, изображения, внутренние страницы и публичный каталог. Использованы предоставленный Safari WebArchive, HTML и дополнительные публичные ресурсы energytool.mts.ru. Каталог — сохранённый снимок, а не обновляемая витрина.

Карта Яндекса требует интернета. Документы и сторонние ссылки открывают внешние сайты. Внешние видеоплееры и встраиваемые сторонние сервисы в автономную копию не входят. Авторизация, личный кабинет, оформление заказов и реальная отправка заявок не подключены. Формы не отправляют данные в МТС. В углу страницы показана отметка локальной копии. Сервер доступен только на этом компьютере, по 127.0.0.1.

Из оригинального HTML убраны вставка AdGuard и скрипты аналитики/профиля. В оригинальном JS адреса сайта и API перенаправлены на локальный сервер; публичный каталог читается из сохранённого JSON, API чата `/api/v1/*` проксируется в Go, остальные API возвращают явное сообщение о локальной демонстрации. Исходники приложения не декомпилировались и дизайн не пересоздавался.

Это отдельная копия для интерфейсного демо. Файлы A2, модели и эксперименты хакатона не изменялись.
