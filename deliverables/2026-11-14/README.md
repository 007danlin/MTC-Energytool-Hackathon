# Материалы защиты EnergyTool

- `presentation.pdf` — финальная презентация, 10 слайдов.
- `demo.mp4` — рабочий сценарий с реальной локальной моделью и синтетическими данными.
- `demo-README.txt` — условия записи.

Инструкция запуска: [README проекта](../../README.md). Проверки и ограничения: [приёмка выпуска](../../docs/release-readiness.md).

Полный ZIP для закрытой сдачи собирается `python3 tools/build_release_bundle.py`. Он дополнительно включает выданную организаторами базу из локальной папки `data`, поэтому сам ZIP и база не публикуются в Git. Сборщик использует подготовленные файлы из `output/pdf` и `output/demo`; опубликованные копии находятся здесь.
