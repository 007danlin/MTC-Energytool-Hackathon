# Итоговая презентация

PDF: `output/pdf/EnergyTool-презентация.pdf`; в комплекте сдачи лежит в корне. 10 слайдов, ориентир рассказа около 7 минут.

1. Сдача ZIP, порядок проверки, запуск и запасная видеозапись.
2. Пользователь и проблема выбора решения.
3. Живая карточка задачи и полезное ожидание.
4. Архитектура: веб, Go, Python, заменяемая модель.
5. Балл N2 69,912; отдельная оценка веба; честная поправка B2 45,877 против A2 55,969.
6. Заявка, очередь, статусы, экспорт и метрики.
7. Специалист и проверенные знания.
8. Контракт модели организаторов и тесты.
9. Фактический замер локальной модели, ошибки и ограничения.
10. План пилота и промышленного внедрения.

Не говорить: «69,9% точности», «закрытый API организаторов уже проверен», «5–7 секунд достигнуты», «заявка ушла в CRM», «пилот доказал рост». Формат ZIP выбран владельцем; доступ жюри к приватному GitHub не открывался.

Для репетиции: каждый участник объясняет основной путь от вопроса до заявки, ограничения модели и свою часть. Подготовка документов не заменяет живую репетицию команды.
