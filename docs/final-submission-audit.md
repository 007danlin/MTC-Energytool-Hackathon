## Условия, которые нельзя объявить полностью закрытыми

**Доступ жюри.** Кейс, стр. 8, связывает доступ к приватному репозиторию со сдачей через PDF и разрешает альтернативный ZIP. Присланный текст формы упоминает доступ `hack-and-change-2026` без явного ограничения по формату. Проверка GitHub показала `permission: none`; владелец явно выбрал самодостаточный ZIP и отказался открывать репозиторий. Архив не зависит от GitHub, но отсутствие отдельного требования доступа для ZIP не подтверждено организаторами. Приглашение не отправлялось.

**Скорость и качество.** Ориентир Q&A 5–7 секунд на локальной модели не достигнут. Веб на модели организаторов отдельно не измерялся. 69,912 — сообщённый public-балл конкурсного N2, не процент точности и не итоговая оценка текущего веба. Программные проверки снижают известные риски, но не доказывают отсутствие любых выдумок. Результаты и ограничения перечислены в `release-readiness.md` и `live-user-audit.md`.

**Закрытие и продолжение.** Кейс, стр. 10, требует нового контекста после закрытия чата. «Новый диалог» создаёт чистую сессию; выход на сайт сохраняет текущую беседу для возврата по требованию владельца. Старые беседы продолжаются только в своей сессии. Эту трактовку временного выхода нельзя выдавать за доказанное соответствие буквальному требованию о закрытии.

**Презентация.** Сохранена выбранная автором версия без редакторских правок. Замечания к её категоричным формулировкам и деталям инструкции остаются в `artem-presentation-review-20261115.md`. Точные пути и фактические ограничения приведены в README комплекта.

Итог: состав самодостаточного ZIP и воспроизводимость запуска проверены. Безусловную гарантию полного выполнения всех функциональных критериев и организационных условий этот аудит не даёт; перечисленные ограничения остаются явными.
