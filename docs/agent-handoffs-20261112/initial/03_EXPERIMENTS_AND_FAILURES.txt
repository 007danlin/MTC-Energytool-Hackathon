ОСОБЕННО ВАЖНО ПО B2
A2/B2 имеют одинаковые prompts, генератор, consultant, dialogue, lexical retrieval,
LLM client и requirements; изменены solution/settings, добавлен hybrid_retrieval.
Дефект _split_query: для многострочного вопроса dense получает только первую
непустую строку, иногда одно «Здравствуйте!». Лексический поиск видит весь вопрос.
TOP_K=4 повышается до 12 даже в режиме a2/fallback, поэтому переключатель B2
не равен исходному A2. Default примера организаторов — 4, реальное значение неизвестно.
Индексирование по 16 документов, startup limit 90 секунд, query timeout 8 секунд
без повторов, выключение dense после 3 ошибок — дополнительные риски, но сбой
платформенного API не доказан. 337.9 секунд не доказывают общий timeout 20 минут.
Исправление этих дефектов разумно проверять, но нельзя заранее назвать их
установленной причиной падения. Новые исправления ещё не имеют платформенного балла.
