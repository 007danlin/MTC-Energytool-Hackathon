Qwen3.8-27B — инструкция для следующего агента

Скачай модель самостоятельно. В этой выгрузке нет весов, установка/генерация
Qwen3.8-27B составителем не выполнялась. Ранее скачивание в другом чате было
остановлено по тогдашнему запросу пользователя; нынешняя задача явно требует
инструкцию следующему агенту скачать модель. Не переносить старую остановку
на эту новую задачу.

ОФИЦИАЛЬНЫЙ ИСТОЧНИК, ПРОВЕРЕН 12.11.2026
https://huggingface.co/Qwen/Qwen3.8-27B
https://huggingface.co/Qwen/Qwen3.8-27B/tree/main
Модель существует в официальном namespace Qwen. В карточке указаны BF16,
поддержка OpenAI-совместимого сервера через vLLM и других движков; репозиторий
около 55.6 GB. Это объём файлов, не гарантия достаточного RAM/VRAM.
Thinking включён по умолчанию; режим влияет на финальный текст и расход токенов.
Сверяй текущую карточку и документацию движка при фактической установке.

ПРЕДВАРИТЕЛЬНО
Проверь ОС, архитектуру, GPU/VRAM, RAM, свободный диск, уже имеющиеся веса.
Для полной копии предусмотрительно иметь хотя бы 70–80 GB свободного диска,
дополнительно место на зависимости и локальные прогоны. Это рабочий запас,
а не требование организаторов. Память для KV-cache и runtime учитывай отдельно.
Не скачивай снова идентичные уже проверенные веса. Восстанови прерванную загрузку
на той же revision. Не подменяй Qwen3.8-27B другой моделью или алиасом qwen30b.
На macOS не обещай работу Linux/CUDA-команды vLLM; выбери совместимый движок
или доступную машину. Квантизация требует явной фиксации формата и ограничений.

СКАЧИВАНИЕ
Из корня распакованного пакета, в отдельное локальное окружение:

python3 -m venv .venv-qwen38
.venv-qwen38/bin/python -m pip install --upgrade huggingface_hub
.venv-qwen38/bin/python scripts/download_qwen38.py --output ./models/Qwen3.8-27B
.venv-qwen38/bin/python -m pip freeze > ./models/download-environment.txt

На Windows используй соответствующие пути Scripts/python.exe.
Скрипт через официальный Hub API определяет commit, сохраняет download-plan,
скачивает snapshot по этому commit и проверяет наличие, размеры, SHA256 файлов.
При повторном запуске использует зафиксированный план. Для другой revision
задай новую папку. Для каждого большого файла сверяет также опубликованный LFS
SHA256, если он есть в метаданных. Не печатает токены доступа.
Документация API скачивания:
https://huggingface.co/docs/huggingface_hub/en/guides/download
Код скрипта проверен на синтаксис; фактическая многогигабайтная загрузка не запускалась.

ЛОКАЛЬНЫЙ СЕРВЕР
Для совместимой Linux/GPU-машины базовый путь из карточки — vLLM. Установи
совместимую версию в отдельное окружение и зафиксируй её; пример запуска
на УЖЕ СКАЧАННЫХ файлах, параметры памяти/контекста выбери по железу:

vllm serve ./models/Qwen3.8-27B --served-model-name Qwen/Qwen3.8-27B --host 127.0.0.1 --port 8000

Это пример, не проверенный запуск на текущем компьютере. Сначала прочитай
актуальный recipe, настрой chat template/thinking и проверь /v1/models,
один /v1/chat/completions и реальное наличие финального content.
Не применяй рекомендуемые настройки карточки вслепую как платформенные:
платформа передаёт TEMPERATURE/MAX_TOKENS, а конфигурация провайдера неизвестна.
Не считать пустой content при заполненном reasoning_content успешной консультацией.
Сохрани stdout запуска, версии библиотек, template hash, precision, effective
параметры, лимит контекста, длительность и finish_reason, без секретов.

ПАРНЫЙ КОНТРОЛЬ
Из project/ (переменные ниже относятся к собственному локальному серверу):

export LLM_BASE_URL=http://127.0.0.1:8000/v1
export LLM_MODEL=Qwen/Qwen3.8-27B
export LLM_API_KEY=local-test
python3 tools/evaluate_zip_live.py --zip artifacts/daniel-submission-a2.zip --questions data/questions.csv --kb data/knowledge-base.zip --output reports/private/qwen38-a2-new --model-label Qwen3.8-27B-exact-revision

Вместо model-label запиши фактическую revision, движок и precision. Ключ local-test
подходит только серверу без реальной авторизации; для авторизованного сервиса
получи ключ из окружения. Не записывай секреты в пакет или логи.
Задай/зафиксируй TEMPERATURE, MAX_TOKENS, MAX_WORKERS, TOP_K, бюджет и контекст
до парного запуска. Папка результата должна быть новой. Затем тем же способом
проверь кандидата, добавь свежий независимый набор. Демо из 18 вопросов — smoke,
а не достаточный тест качества.
Для hybrid отдельно подними/проверь embeddings и полный путь без кеша; проверь
ограничения harness по пробрасываемым переменным перед использованием.

ЧТО СЧИТАТЬ ДОКАЗАТЕЛЬСТВОМ
Model manifest + проверенный запуск + новые парные ответы на одинаковом стенде.
Замена строки model в настройке старого Ollama не меняет веса и не подходит.
Совпадение имени Qwen3.8-27B с платформой уменьшает один источник расхождения,
но не раскрывает judge/golden/precision провайдера и не гарантирует рост Score.
