# Синхронизация после переименования истории

По просьбе владельца все заголовки коммитов во всех опубликованных ветках переведены на короткий русский язык. Содержимое файлов, авторы, даты и структура слияний сохранены; SHA коммитов изменились. Резервный Git bundle сохранён владельцу отдельно от комплекта сдачи.

Самый простой путь для коллег: сохранить свои незакоммиченные изменения/ветки и клонировать репозиторий в новую папку. Старую папку оставить до переноса своей работы. Не выполнять обычный merge/pull старой истории в новую: он вернёт старые коммиты.

Для просмотра новой истории без изменения локальной ветки:

```bash
git fetch origin
git switch --detach origin/main
```

Сначала сохраните свои изменения. Переносите только собственные незалитые изменения, проверяя diff; не переносите повторно уже слитые PR #10 и #11.
