# Веб-стек

Актуальные запуск, переменные и порядок проверки находятся в [README](../README.md). `docker compose up --build -d` поднимает веб, Go и Python. `compose.web.yaml` сохранён для совместимости. Конфигурация модели нейтральная, локальная Ollama необязательна.

Веб использует N2-поиск с ограниченным контекстом и проверяемый JSON. API очереди, метрик, специалиста и проверенных знаний подключены. Для хранения сессий и снимка знаний используются отдельные тома; Python читает снимок без прав записи. Пакетный ML-запуск вынесен в `compose.submit.yaml`.

[Приёмка выпуска](release-readiness.md), [контракт бизнеса](business-contract.md), [контракт специалиста](expert-contract.md). Исторические замеры и ранняя версия запуска не являются инструкцией для текущего выпуска.
