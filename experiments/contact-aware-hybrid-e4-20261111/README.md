# E4 — избирательное дополнение контекста A2

Отдельный замороженный эксперимент. Рабочий A2 с платформенным баллом 55.969 и корневой runtime не изменяются.

Сохраняются все принятые полные разделы A2 и их порядок. До четырёх новых разделов плотного поиска с ограничениями продукта добавляются в пределах 6000 дополнительных символов и общего исходного лимита. Расширение выполняется только при отсутствии хотя бы двух из трёх первых плотных результатов в принятом контексте A2. При передаче телефона или email с намерением связаться контекст остаётся исходным. Новые пользовательские данные в историю не подставляются; вопрос, промпт и параметры генерации не меняются.

Индекс использует проверенную версию BGE-M3 и контрольные векторы. При несовместимости кодировщика, базы или ошибке API плотная ветка отключается и используется исходный поиск A2. Совместимость с реальным API платформы не подтверждена.
