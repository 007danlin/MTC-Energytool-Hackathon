# E2: дополнение контекста A2 без удаления источников

Отдельный эксперимент по запросу пользователя от 11 ноября 2026. A2 с платформенным результатом 55.969 остаётся рабочей версией; G51.729 и E1 сохранены. Код в корне проекта не изменён.

E2 использует готовый индекс BGE-M3 из E1 и его проверки совместимости, целостности и отказа API. Изменён только способ объединения результатов: весь исходный список A2 остаётся неизменным префиксом, затем добавляются максимум четыре отсутствующих раздела среди первых12 результатов плотного поиска. Вместе с разделом добавляются полные ограничения и требования его продукта. Весь пакет добавляется только при достаточном месте; лимит добавлений6000символов и общий лимит контекста32000символов не превышаются. Если ограничение из исходного списка не вошло в бюджет, нельзя добавлять новое утверждение из того же продукта без этого ограничения.

Поисковый запрос, промпт, настройки генерации и документы не изменены. Эмбеддинги документов и35 ранее открытых запросов повторно не считались. Ошибка API, несовместимость модели или изменение базы возвращают исходный поиск A2. На реальном API платформы совместимость пока не проверена.

`tests/test_index.py` и `tests/test_preservation.py`:21 автоматическая проверка. Сравнение35вопросов при лимитах4000/32000/90000:105 проверок сохранения фактически включённого контекста A2. Это инвариант содержимого запроса, а не гарантия качества генерации.

Состояние, исходные ответы, рубрики, журналы и сборщик находятся в `reports/private/preserving-hybrid-e2-20261111/`. В `experiment.json` до генерации закреплены условия допуска. Промежуточный ZIP хранится там же и не предназначен для отправки до завершения проверки качества. Публикация нового архива в `artifacts/` разрешена только при прохождении сравнения и контрольных проверок; A2 сохраняется в любом случае.
